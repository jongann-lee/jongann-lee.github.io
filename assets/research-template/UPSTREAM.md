Preserve the research-page footer attribution. This license covers the page design; research materials retain their own rights.

CSS and JavaScript files are copied unchanged from the sibling template checkout's `static/` directory. Only assets needed by the page and its template scripts are included. Example photos, videos, PDFs, favicon, tracking snippets, and placeholder metadata are not included.

The IROS and SIEVE pages use the template's hero, author/resource links, content sections and BibTeX copy button. The More Works dropdown links back to the portfolio. The overview uses the IROS poster’s content within the original template’s single-column content sections; unused teaser, video, carousel and poster-iframe sections are omitted. The scroll-to-top button uses Bulma’s `is-hidden-mobile` utility to avoid overlapping the mobile Portfolio button. No new CSS is introduced.

SIEVE reuses the native teaser figure, abstract and single-column content sections with source-paper figures; template CSS and JavaScript remain unchanged.
