Navigating in Uncertain Environments with Heterogeneous Visibility

Jongann Lee, Melkior Ornik
University of Illinois Urbana-Champaign
IROS 2026
Paper Code arXiv Poster

Introduction

Traditional path planning under uncertainty, such as the Canadian Traveller Problem (CTP) and Informative Path Planning (IPP), often overlooks heterogeneous visibility.

In real-world environments, vantage points offer varying levels of information. We propose a framework that:

  • Exploits High-Visibility Nodes: Leverages non-local sensing to observe distant edges from specific vantage points.
  • Balances Exploration/Exploitation: Uses an observation reward combined with traversal costs to balance both.

Our approach prioritizes informative vantage points when planning in high-uncertainty environments.

Problem Setting

The environment is modeled as a graph G = (V, E) with source vs and target vt.

Key Components:

  • Traversal Cost: Each edge e has a cost c(e).
  • Visibility Mapping: vis(v) ⊆ E defines edges observable from node v.
  • Edge Blockages: A subset Eb ⊂ E is statically blocked. No prior knowledge of the probability distribution of blockages is assumed.

Objective: Navigate from vs to vt with minimum cumulative traversal cost.

Since minimum path cost is a random variable, the policy should balance information gain with path cost minimization.

Short Diverse Path Sampling

We generate a path tree of depth r by recursively branching n times, where each branch represents a shortest path computed after removing all edges within an m-hop radius of a node sampled from the parent path.

Path Generation

We define a path reward R(P) that balances cost-efficiency with the information gain of visiting high-visibility nodes.

1. Edge Utility (U): An edge’s utility is based on its frequency in the diverse path set, weighted by depth in the sampled tree.

2. Observation Reward (Robs): The sum of utilities for all currently unobserved edges visible from node v:

Robs(v)=∑e∈vis(v)U(e)(1−1obs(e))

Already observed edges contribute no further reward, including when encountered again along a candidate path.

3. Overall Path Reward:

R(P)=λ∑v∈PRobs(v)−∑e∈Pc(e)

The path with the highest reward is selected from a second sampled path tree. The weight λ controls the importance of observation.

Experiment: Plateau

We test on a grid with plateaus (high visibility, high entry cost). Chokepoint edges have an independent blockage probability p (not used during planning). We compare our method against a Shortest Path (SP) baseline and RPP.

Discussion

Baseline Equivalence: At λ = 0, the proposed agent’s behavior is equivalent to that of the Shortest Path (SP) agent.

Observation Weighting: Increasing λ assigns higher priority to edge observations, improving performance in these environments when blockages are likely.

With no blockages, the observation detour increases cost on the natural terrain map. These experiments are simulations, including the map based on real-world topographical data.
